# دستیار شخصی سلامت 🩺

## راه‌اندازی روی GitHub Codespaces

1. یه ریپازیتوری جدید و **خالی** روی GitHub بسازید (بدون README، بدون gitignore).
2. تمام فایل‌های این پروژه رو داخل اون ریپازیتوری آپلود کنید (یا با گیت push کنید).
3. روی صفحه‌ی ریپازیتوری، دکمه‌ی سبز **Code** رو بزنید → تب **Codespaces** → **Create codespace on main**.
4. چند ثانیه صبر کنید تا Codespace ساخته و پکیج‌ها به‌صورت خودکار نصب بشن (`npm install`).
5. در ترمینال پایین صفحه بنویسید:
   ```
   npm run dev
   ```
6. یه پنجره‌ی کوچیک پایین سمت راست میاد که می‌گه پورت 5173 باز شده — روی **Open in Browser** بزنید. سایت‌تون بالا میاد 🎉

اگه پنجره باز نشد، از تب **PORTS** (کنار ترمینال) روی پورت 5173 کلیک کنید.

## توسعه‌ی بیشتر
- دیتابیس غذاها: `src/data/foods.js`
- حرکات باشگاهی: `src/data/exercises.js`
- مدال‌ها: `src/data/achievements.js`
- متن‌ها و ترجمه‌ها: `src/i18n.js`
- منطق و ذخیره‌سازی: `src/context/AppContext.jsx`

همه‌ی اطلاعات کاربر داخل مرورگر خودش (`localStorage`) ذخیره می‌شه؛ نیازی به سرور یا دیتابیس نیست.
